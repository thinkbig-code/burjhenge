# Burjhenge

Where to stand today to see the sun set (or rise) exactly on the spire of Burj Khalifa.

- `index.html` is the one-picture version: today's spot, the moment, a route there.
- `map.html` is the detailed version with the map and the year strip.

Everything runs in the browser. The sun position follows the standard low-precision solar formulas (checked against the NOAA algorithm to about 0.01°). Coastline and Sheikh Zayed Road: © OpenStreetMap contributors, ODbL.
